# Contributing

Use Node.js 20+. Run `npm install`, `npm test`, and `npm run check:release`. Add offline fixtures for provider changes; tests must not require credentials or paid calls. Keep changes focused, preserve source traceability, and never commit private exports, credentials, cookies, or customer data. Open a pull request describing behavior, tests, privacy impact, and provider cost impact. A code of conduct and public contribution governance remain release-owner decisions.
