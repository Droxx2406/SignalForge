# Release checklist

- [ ] Approve final project name and open-source license.
- [ ] Review all release-candidate files and synthetic examples.
- [ ] Run `npm run validate` on a clean checkout.
- [ ] Confirm demo works without credentials.
- [ ] Reverify each enabled live provider without exceeding approved budgets.
- [ ] Review dependency and upstream attribution obligations.
- [ ] Run secret scanning against the actual Git index and full history.
- [ ] Confirm no private Notrix files, reports, media, binaries, or machine paths are tracked.
- [ ] Add an approved private security contact.
- [ ] Manually commit and publish only after owner approval.
